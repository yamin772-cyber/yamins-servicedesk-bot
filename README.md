🤖 Yamin's Service Desk Assistant

A lightweight Service Desk knowledge assistant built using HTML, CSS, and JavaScript.

This project was created as a proof of concept to help Service Desk analysts quickly find troubleshooting guidance, common fixes, and escalation information.

🚀 Features
Quick issue lookup
Outlook troubleshooting guidance
VPN troubleshooting guidance
Account lockout support
Interactive chat-style interface
Command buttons
Browser-based application
No installation required

📚 Current Knowledge Articles
Outlook Authentication Issues
VPN Connection Failure
Locked Account

🖥️ How to Use
Open the application.
Type an issue into the search box.
Press Enter or click Ask.
Follow the provided resolution steps.

Example Searches
outlook password
vpn issue
locked account
email not working

⚡ Available Commands
Command	Description
🗑️ Clear	Clears the conversation
❓ Help	Displays available commands
📚 Articles	Lists available knowledge articles
ℹ️ Version	Displays application version
